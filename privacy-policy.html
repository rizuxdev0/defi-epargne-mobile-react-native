Politique de Confidentialité

Application : Défi Épargne • Dernière mise à jour : 26 Septembre 2026

Résumé clair : Défi Épargne est une application locale d'auto-discipline financière. Vos montants épargnés, vos objectifs et vos historiques restent stockés exclusivement sur votre téléphone. Aucune donnée n'est envoyée à des serveurs tiers ni vendue.

1. Collecte et Stockage des Données

L'application Défi Épargne fonctionne selon une architecture Offline-First / Stockage Local :

  • Données financières et d'épargne : Vos défis, versements, dates et montants sont stockés exclusivement dans la mémoire sandbox interne de votre appareil mobile.
  • Préférences de profil : Votre prénom, avatar choisi, devise et paramètres d'affichage restent sur votre appareil.
  • Code PIN : Si vous configurez un code PIN de verrouillage, il est vérifié localement sur l'appareil.

2. Utilisation de l'Intelligence Artificielle (RIZUX IA / Google Gemini)

L'application propose un assistant d'analyse financière :

  • Mode Local par défaut : RIZUX IA fonctionne 100% hors-ligne sur votre téléphone sans aucune transmission de données sur Internet.
  • Mode Cloud (Optionnel) : Si vous choisissez d'activer la connexion Google Cloud en fournissant votre propre clé API Google Gemini (AI Studio), les requêtes textuelles de conseil sont transmises de manière chiffrée (HTTPS) directement aux serveurs de Google (Alphabet Inc.) selon les règles de confidentialité de Google Cloud. Aucune donnée bancaire sensible ou confidentielle n'y est transmise.

3. Permissions demandées

  • Notifications locales (VIBRATE, SCHEDULE_EXACT_ALARM, RECEIVE_BOOT_COMPLETED) : Utilisées uniquement pour programmer et délivrer vos rappels quotidiens d'épargne sur votre appareil.
  • Accès Internet (INTERNET) : Uniquement requis si vous activez les conseils du coach avec une clé Google Gemini connectée ou pour partager une sauvegarde JSON.

4. Partage avec des tiers

Nous ne vendons, ne louons, n'échangeons et ne transférons aucune information personnelle identifiable à des tiers. L'application ne contient aucune régie publicitaire ni traceur de profilage commercial.

5. Sauvegarde et Exportation

Vous disposez d'un contrôle total sur vos données : vous pouvez à tout moment exporter une copie de votre base de données au format JSON ou réinitialiser intégralement vos données depuis les Paramètres de l'application.
